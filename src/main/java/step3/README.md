# 3단계 - 자동차 경주

## 기능

- 자동차 대수를 2 이상 10 이하 숫자로 입력받을 수 있다. 그 이외의 숫자를 입력하면 예외를 발생시킨다.
- 시도할 횟수를 1 이상 10 이하 숫자로 입력받을 수 있다. 그 이외의 숫자를 입력하면 예외를 발생시킨다.
- 시도할 횟수보다 많은 횟수로 자동차를 이동시키려고 하면 예외를 발생시킨다.
- 입력받은 자동차 대수만큼 생성한 자동차를 식별 번호와 함께 리스트로 반환한다.
- 특정 조건은 외부에서 주입받을 수 있다.
- 시도할 때마다 0 또는 1을 전진한 전체 자동차(식별번호, 전진한 거리)를 리스트로 반환한다.

## 고민한 것

- 자동차 경주를 화면에 출력하는 UI와 자동차 경주 객체를 경주 객체에 대해서만 단위 테스트를 작성해보았습니다.
- 전진하는 조건에 대해서 랜덤을 사용하여 테스트가 어려워서 테스트하기 좋은 구조로 변경해보았습니다.
  - 요구사항에서 자동차 경주의 특수 조건은 랜덤이라 외부에서 주입받을 수 있더라도 자동차 경주 객체 내부에 생성해두는 것이 좋을지 없으면 예외를 발생하도록 구현하는 것이 좋을지 고민했습니다.

## 이전 피드백

- 변수명에 stringArray와 같이 타입, 자료 구조를 쓰는 것은 지양한다.
    - AI 피드백 활용하여 변수명을 개선한다.
- 테스트 데이터를 선정할 때 무조건 데이터가 많은 것이 좋은 것은 아니기 때문에, 정말 필요한 데이터만 선정한다.
