# todo

## Car
- [ ] 숫자가 4 이상 입력 받을 경우 앞으로 전진한다.
- [ ] 이름을 반환한다.
- [ ] 위치를 반환한다.
- [ ] 다른 자동차보다 더 멀리 갔는지 확인한다.
- [ ] 다른 자동차와 같은 위치에 있는지 확인한다.

## RacingGame
- [ ] 경주 횟수를 입력받는다.
- [ ] 경주 회수가 모두 끝나야지 경주가 끝난다.
- [ ] 경주시 경주 결과를 반환한다.

## RemainingRounds
- [ ] 시도 횟수는 1 이상이여야 한다.
- [ ] 남은 라운드가 없을 때 확인할 수 있다.
- [ ] 남은 라운드가 없을 때 라운드를 진행할 수 없다.

## Cars
- [ ] 자동차 이름을 문자열로 입력받는다. 자동차 이름은 쉼표(,)를 기준으로 구분하고 구분한 이름 개수만큼 자동차를 생성한다.
- [ ] 자동차 목록을 반환한다.
- [ ] 가장 멀리간 자동차 목록을 반환한다.
- [ ] 자동차들을 이동시킨다.

## CarName
- [ ] 자동차 이름은 5자를 초과할 수 없다.
- [ ] 자동차 이름은 비어 있거나 공백만으로 이루어질 수 없다.

## Position
- [ ] 위치는 0 이상이어야 한다.
- [ ] 전진 시 위치가 1 증가한다.
- [ ] 다른 위치와 비교해 현재 위치가 더 작으면 음수, 같으면 0, 더 크면 양수를 반환한다.
