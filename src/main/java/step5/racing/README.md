## Step 5 기능 구현 사항
- [x] 입력이 공백이면 예외가 발생한다
- [x] 자동차 이름을 입력받는다
  - [x] 자동차 이름이 5자를 초과하면 예외가 발생한다
  - [x] 자동차 이름은 쉽표를 기준으로 구분한다
  - [x] 자동차 경주를 위해 자동차는 2대 이상 입력받야아 한다
  - [x] 자동차 이름은 중복될 수 없다
- [x] 시도할 회수를 입력받는다
  - [x] 시도할 회수가 숫자가 아니면 예외가 발생한다
  - [x] 시도할 회수가 1 이상이 아니면 예외가 발생한다
- [x] 자동차의 위치를 나타낸다
  - [x] 자동차의 위치는 양수여야 한다
  - [x] 전진할 때 1씩 증가한다
- [x] 모든 자동차를 생성한다
  - [x] 각 자동차를 생성한다
    - [x] 입력받은 이름으로 자동차를 생성한다
    - [x] 자동차를 생성할 때 위치는 0으로 설정한다
- [x] 랜덤값을 생성한다
  - [x] 랜덤값은 0과 9사이여야 한다
- [x] 랜덤값이 4 이상이라면 자동차는 전진한다
- [ ] 자동차 경주를 진행한다
  - [x] 각 라운드별로 모든 자동차의 위치를 판단한다
    - [x] 각 라운드별로 모든 자동차를 이동한다(정지, 이동)
      - [x] 각 자동차의 이동을 결정한다
  - [ ] 각 라운드별 자동차의 위치를 자동차의 이름과 함께 출력한다
    - [ ] 각 라운드별 자동차의 결과를 저장한다
      - [x] 각 자동차의 결과를 생성한다
- [ ] 우승자를 출력한다
  - [ ] 가장 멀리간 자동차가 우승한다
  - [ ] 우승자는 한명 이상일 수 있다
