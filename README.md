# 자동차 경주 게임
## 진행 방법
* 자동차 경주 게임 요구사항을 파악한다.
* 요구사항에 대한 구현을 완료한 후 자신의 github 아이디에 해당하는 브랜치에 Pull Request(이하 PR)를 통해 코드 리뷰 요청을 한다.
* 코드 리뷰 피드백에 대한 개선 작업을 하고 다시 PUSH한다.
* 모든 피드백을 완료하면 다음 단계를 도전하고 앞의 과정을 반복한다.

## 온라인 코드 리뷰 과정
* [텍스트와 이미지로 살펴보는 온라인 코드 리뷰 과정](https://github.com/next-step/nextstep-docs/tree/master/codereview)

## 기능 목록

- [x] 자동차는 숫자가 4이상이면 전진한다 (4 -> 위치 + 1)
- [x] 자동차는 숫자가 3이하면 멈춘다 (3 -> 위치 0)
- [x] 랜덤숫자 생성기는 0~9사이의 숫자를 생성한다
- [x] 자동차는 생성직후 위치가 0이다
- [x] 자동차 여러대를 각각 랜덤숫자에 맞춰 전진하거나 멈춘다
- [x] 자동차 대수와 시도 횟수를 입력받는다
- [x] 라운드가 끝나며 자동차의 상태를 출력한다 
- [x] 라운드 1로 시작한 게임은 play 1번 후 끝난다(1, play 1번 -> 종료)
- [x] 라운드 2로 시작한 게임은 play 1번 후 끝나지 않는다(2, play 1번 -> 진행중)
- [x] 자동차는 이름을 가진다 ("pobi" -> 이름 pobi)
- [x] 자동차 이름이 5자를 넘으면 예외를 발생한다 ("pobiii" -> 예외)
- [x] 자동차 이름은 쉼표로 구분해서 입력받고, 이름 수만큼 자동차를 만든다
- [x] 이름 수 만큼 자동차를 만든다 (["pobi", "crong"] -> 2대)
- [x] 가장 멀리 간 자동차가 우승한다 (pobi 3, crong 2 -> pobi)
- [x] 가장 멀리 간 자동차가 여럿이면 모두 우승한다 (pobi 3, crong 3, honux 1 -> pobi, crong)
- [x] 출력할 때 이름을 같이 찍는다 (pobi : ---)
- [ ] 게임이 끝나면 우승자를 알려주고, 여러 명이 우승할 수 있다


### 고민들
숫자를 랜덤으로 던져서 확인하게되면 테스트가 실패함
인터페이스를 통해 일반적인 숫자생성기와 테스트용 고정숫자 생성기를 활용

4단계부터 Car에 이름이 생기면서 생성자로 이름을 받아서 저장하려고하니 기존 테스트코드가 문제가 생기는데
이런 경우에는 기본생성자를 남겨둘지 없애고 통일하면서 테스트코드를 고칠지
