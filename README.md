## 진행 방법
* 자동차 경주 게임 요구사항을 파악한다.
* 요구사항에 대한 구현을 완료한 후 자신의 github 아이디에 해당하는 브랜치에 Pull Request(이하 PR)를 통해 코드 리뷰 요청을 한다.
* 코드 리뷰 피드백에 대한 개선 작업을 하고 다시 PUSH한다.

## 자동차 경주 게임 TDO LIST

### 기능 요구사항 체크리스트
- [x] 랜덤 값은 0에서 9 사이로 만들어진다. (생성 범위가 10이면 항상 0~9)
- [x] 자동차의 최초 전진 상태는 0 이다.
- [x] 값이 4 이상이면 자동차는 전진한다. (6 → 전진)
- [x] 값이 4 이면 자동차는 전진한다. (경계값 테스트)
- [x] 값이 4 미만이면 자동차는 멈춘다. (2 → 멈춤)
- [x] 자동차의 현재 전진 상태를 int 값으로 알 수 있다. (현재 전진 상태가 5라면 5)
- [x] 자동차 대수만큼 자동차가 만들어진다. (3대 → 3대)
- [x] 자동차 대수가 0이거나 음수이면 RuntimeException (0, -1) (직접 정한 부분)
- [x] 시도 횟수가 0이거나 음수이면 RuntimeException (0, -1) (직접 정한 부분)
- [x] N회 시도하면 어떤 자동차도 N칸을 넘어 전진하지 않는다. (5회 → 위치 ≤ 5)
- [x] 이미 진행한 레이싱 게임을 다시 진행하면 RuntimeException (직접 정한 부분)
- [x] 사용자가 자동차 대수와 시도 횟수를 입력한다. (UI, 단위 테스트 제외)
- [x] 자동차의 상태를 화면에 출력한다. (UI, 단위 테스트 제외)
