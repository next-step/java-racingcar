- [X] 랜덤 값이 4이상이면 자동차는 전진한다(5 -> 위치 1증가)
- [X] 랜덤 값이 4보다 작으면 자동차는 이동하지 않는다(3 -> 위치 그대로)
- [ ] 자동차 개수를 입력하면 개수에 맞는 자동차가 생성된다.(3 -> 자동차 3개 생성)
- [ ] 시도 횟수를 입력하면 입력 횟수 만큼 이동이 가능하다(3 -> 이동 가능 횟수 3)
- [ ] 시도 횟수가 0 또는 음수이면 IllegalArgumentException 예외가 발생한다.(0은 요구사항에 없어서 내가 정한 규칙)
- [ ] 시도 횟수가 정수가 아니면 IllegalArgumentException 예외가 발생한다.(시도 입력 -> ";")
- [ ] 자동차 개수가 문자이면 IllegalArgumentException 예외가 발생한다.(자동차 개수 입력 -> ";")
- [ ] 자동차 개수가 음수이면 IllegalArgumentExceptino 예외가 발생한다.(자동차 개수 입력 -> "-4")
