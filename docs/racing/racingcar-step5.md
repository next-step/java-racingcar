# Racing Car todos (step5)
## 차
- [x] 차 이름과 위치를 가진다.
  - [x] (추가 조건) 위치는 음수일 수 없다.
- [x] 숫자를 입력받아 4 이상이면 전진한다.
- [x] 현재 이름과 위치를 차 결과로 반환한다.
- [x] (리뷰 반영) 문자열 이름으로도 생성할 수 있다.

## 차 이름
- [x] 자동차 이름은 5자를 초과할 수 없다.
  - [x] (추가 조건) 자동차 이름은 공란이거나 빈 칸일 수 없다.

## 경기
- [x] 차 이름 목록과 시도할 횟수, 번호 생성기를 입력받아 경기를 진행한다.
- [x] 각 회차마다 경기를 진행하고, 회차 결과를 반환한다.
- [x] 경기가 진행중인지 판단 가능하다.
- [x] (추가 조건) 경기가 끝난 뒤 회차를 진행하면 예외가 발생하고, 차들은 움직이지 않는다.

## 차 목록
- [x] (추가 규칙) 차 이름에 중복은 있어선 안된다.
- [x] (추가 규칙) 차 목록은 null이거나 비어 있을 수 없다.
- [x] 생성된 숫자에 따라 각 차를 움직인다.
- [x] 현재 차들의 상태를 회차 결과로 반환한다.

## 회차 결과
- [x] 차들간의 거리를 비교해 우승자를 구할 수 있다.
  - [x] 우승자는 여럿일 수 있다.
- [x] (추가 규칙) 결과는 이후 경기가 진행돼도 바뀌지 않는다.

## 시도할 횟수
- [x] 초기화할 때에는 0보다 큰 정수다.
- [x] 한 회차가 진행되면 1 감소한다.
  - [x] (추가 조건) 0일 때 감소하면 예외가 발생한다.
- [x] 값이 0 보다 크면 회차를 진행할 수 있다.

## 입력
- [x] 자동차 이름을 입력받는다.
- [x] 자동차 이름은 쉼표(,)를 기준으로 구분한다.
  - [x] (추가 조건) 빈 입력이 들어올 수 없다.
  - [x] (추가 조건) 쉼표 전후의 공백은 잘라낸다.
- [x] 시도할 횟수를 입력받는다.
  - [x] (추가 조건) 양수여야 한다.

## 출력
- [x] 각 회차마다 회차 결과를 받아 진행상태를 출력한다.
- [x] 회차를 마친 후 우승자 목록을 전달받아 우승자를 출력한다.
