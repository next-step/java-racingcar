# Racing Car todos (step5)
## 차
- [x] 차 이름과 위치를 가진다.
  - [x] (추가 조건) 위치는 음수일 수 없다.
- [x] 숫자를 입력받아 4 이상이면 전진한다.

## 차 이름
- [x] 자동차 이름은 5자를 초과할 수 없다.
  - [x] (추가 조건) 자동차 이름은 공란이거나 빈 칸일 수 없다.

## 경기
- [ ] 차 이름 목록과 시도할 횟수, 번호 생성기를 입력받아 경기를 진행한다.
- [ ] 각 회차마다 경기를 진행하고, 차 목록을 반환한다.
- [ ] 경기가 진행중인지 판단 가능하다.

## 차 목록
- [ ] 차들간의 거리를 비교해 우승자를 구할 수 있다.
  - [ ] 우승자는 여럿일 수 있다.
- [ ] (추가 규칙) 차 이름에 중복은 있어선 안된다.

## 시도할 횟수
- [ ] 초기화할 때에는 0보다 큰 정수다.
- [ ] 한 회차가 진행되면 1 감소한다.
- [ ] 값이 0 보다 크면 회차를 진행할 수 있다.

## 입력
- [ ] 자동차 이름을 입력받는다.
- [ ] 자동차 이름은 쉼표(,)를 기준으로 구분한다.
  - [ ] (추가 조건) 빈 입력이 들어올 수 없다.
  - [ ] (추가 조건) 쉼표 전후의 공백은 잘라낸다.
- [ ] 시도할 횟수를 입력받는다.
  - [ ] (추가 조건) 양수여야 한다.

## 출력
- [ ] 각 회차마다 차 목록을 받아 진행상태를 출력한다.
- [ ] 회차를 마친 후 우승자 목록을 전달받아 우승자를 출력한다.
