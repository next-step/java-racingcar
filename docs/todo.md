# 문자열 덧셈 계산기

## 기능 목록 (todo)

- [x] (`,`, `:`)를 기준으로 문자열을 분리 후 합을 반환한다 (“1,2” → 3, “1:2" → 3, “1,2:3” → 6)
- [x] //와 \n 사이의 문자를 커스텀 문자로 지정해서 분리 후 합을 반환한다 (“//;\n1;2;3" → 6)
- [x] 구분문자, 커스텀문자를 기준으로 문자를 분리한다
- [x] null 또는 ""이면 0을 반환한다
- [x] 음수를 전달하거나 문자를 전달하는 경우 RuntimeException예외를 던진다 (“-1,2”, “a,1")

## 프로그래밍 제약 조건

- [x] indent(들여쓰기) depth는 1까지만 허용한다
- [x] else를 쓰지 않고 early return으로 처리한다
