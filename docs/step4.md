# 🚀 4단계 - 자동차 경주(우승자)

## 구현할 기능 목록

- [x] 자동차는 이름을 가진다
- [x] 자동차 이름이 5자를 넘으면 예외가 발생한다
- [x] 쉼표로 구분된 이름의 수만큼 자동차를 만든다
- [x] 가장 멀리 간 자동차가 우승한다
- [x] 가장 멀리 간 자동차가 여럿이면 모두 우승한다
- [x] 자동차 이름을 쉼표로 구분해 입력받는다
- [x] 자동차의 이름과 위치를 함께 출력한다
- [x] 우승자를 쉼표로 구분해 출력한다

## 리팩토링

- [x] `CarMover`의 이동 조건 판단을 `Car.move(int)`로 옮긴다
- [ ] `race()`가 경주만 담당하고 결과 조회를 분리한다
