# 🚀 2단계 - 문자열 덧셈 계산기

## 기능 요구사항

- [x] "" 를 입력하면 0을 반환한다
- [x] null 을 입력하면 0을 반환한다
- [x] "1" 을 입력하면 1을 반환한다
- [x] 기본 구분자로 구분된 숫자의 합을 반환한다
  - [x] "1,2" 를 입력하면 3을 반환한다
  - [x] "1:2" 를 입력하면 3을 반환한다
  - [x] "1,2:3" 을 입력하면 6을 반환한다
- [x] "//;\n1;2;3" 을 입력하면 6을 반환한다
- [x] "-1,2" 를 입력하면 RuntimeException 이 발생한다
- [x] "a,1" 을 입력하면 RuntimeException 이 발생한다
