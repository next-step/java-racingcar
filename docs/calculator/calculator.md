## 계산기 todos
- [ ] null 또는 빈 문자열이 들어왔을때 0을 반환한다
- [ ] 쉼표 또는 콜론으로 구분된 숫자의 합을 반환한다
- [ ] “//“와 “\n” 사이의 커스텀 구분자로 구분된 숫자의 합을 반환한다 
  - (결정필요) “//“와 “\n” 사이 여러 문자가 들어있는 경우 각각을 구분자로 쓸 것인가, 해당 패턴을 구분자로 볼 것인가, 잘못된 입력으로 보고 예외를 던질 것인가
  - (결정필요) “//“와 “\n” 사이 빈 경우 커스텀 구분자 없이 정상 동작할 것인가, 잘못된 입력으로 보고 예외를 던질 것인가
- [ ] 음수가 들어있는 경우 RuntimeException
- [ ] 숫자와 구분자 외 문자가 들어있는 경우 RuntimeException
