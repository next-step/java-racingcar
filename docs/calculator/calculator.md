## 계산기 todos
- [X] 빈 문자열이 들어왔을때 0을 반환한다.
  - [X] (추가규칙) null의 경우 0을 반환한다.
- [X] 쉼표 또는 콜론으로 구분된 숫자의 합을 반환한다
  - [X] (추가규칙) 하나만 입력된 경우 해당 수를 반환한다
  - [X] (추가규칙) 구분자 사이에 빈 문자열인 경우 0으로 본다
- [ ] “//“와 “\n” 사이의 커스텀 구분자로 구분된 숫자의 합을 반환한다 
  - [ ] (추가규칙) 커스텀 구분자를 지정해도 쉼표와 콜론 또한 구분자로 사용한다
  - [ ] (추가규칙) “//“와 “\n” 사이 여러 문자가 들어있는 경우 RuntimeException
  - [ ] (추가규칙) “//“와 “\n” 사이 빈 경우 RuntimeException
  - [ ] (추가규칙) “//“와 “\n” 사이 숫자가 들어온 경우 RuntimeException
  - [ ] (추가규칙) “//“와 “\n” 사이 -가 들어온 경우 RuntimeException
- [X] 음수가 들어있는 경우 RuntimeException
- [ ] 숫자와 구분자 외 문자가 들어있는 경우 RuntimeException
